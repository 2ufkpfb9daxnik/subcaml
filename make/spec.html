主な仕様と制限

カリー化と部分適用

関数はカリー化されます。複数の引数を受け取る関数は、 一つの引数を受け取って関数を返す関数として扱われます。 

let add x y = x + y
        let add3 = add 3
        let result = add3 5

関数に一部の引数だけを与える部分適用も使用できます。 上の例では、add3の型は int -> intです。

評価順序

式、演算子の引数、関数の引数、組やレコードの要素は、 左から右へ評価されます。 &&と||は短絡評価されます。

文字列と文字

stringは不変の文字列型です。 文字列を書き換えることはできません。 文字列の連結には^を使用します。

charは一文字を表す型です。 文字列中の文字はString.getで読み出します。

let多相

letで定義された値の型は、可能な場合に一般化されます。 

let id = fun x -> x

        let n = id 1
        let b = id true

この例のidは 'a -> 'a型として使用できます。

値制限

参照などの副作用と型安全性を両立させるため、 型変数の一般化には値制限を適用します。 関数、定数、コンストラクタなどの値は一般化できますが、 一般の関数適用や参照の生成は原則として一般化しません。

等価性と順序比較

=と<>は、同じ型の値を比較します。 整数、真偽値、浮動小数点数、文字、文字列、組、 レコード、ヴァリアント、リスト、参照を比較できます。 関数値の比較は実行時エラーとします。

<、<=、>、 >=も同じ型の値を比較します。 ただし、関数値には使用できません。
