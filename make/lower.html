低水準中間表現

クロージャ中間表現にデータ表現の具体化を行い、 抽象的なブロック、クロージャ、定数、プリミティブ演算を、 ヒープ確保、メモリ操作、低水準演算、関数呼出しへ変換します。

  • クロージャ中間表現
  • ↓ データ表現の具体化
  • 低水準中間表現

この段階では、通常の実行時値を64ビットの1ワードとして扱います。 即値はワード内に直接格納し、複合値はヒープまたは静的データ領域への ポインタとして表します。

低水準中間表現は、まだ特定の物理CPUや仮想CPUの命令セットには依存しません。 変数は引き続き個数制限のない一時変数であり、 命令選択、仮想レジスタへの対応付け、基本ブロック化は次の段階で行います。

プログラムの構文

低水準中間表現のプログラムは、外部関数宣言、静的データ、 関数定義、大域値定義、およびプログラム本体から構成されます。 プログラムを P、 外部関数宣言を X、 静的データを D、 関数定義を F、 大域値定義を G、 式を e で表します。

構文 名称 説明
P ::= X1 ... Xl D1 ... Dm F1 ... Fn G1 ... Gp in e 低水準プログラム 外部関数宣言、静的データ、関数定義、大域値定義、 およびプログラム本体をまとめたもの

外部関数宣言の構文

構文 名称 説明
X ::= external f = name 外部関数宣言 内部識別子 fを、ランタイムまたは外部環境の関数 nameへ対応付ける

静的データの構文

コンパイル時に内容が確定する文字列、浮動小数点数、 定数ブロックは静的データ領域へ配置します。 静的データのラベルを l、 1ワードの定数を w で表します。

構文 名称 説明
D ::= string l s 文字列定数 ラベル lの位置へ文字列 sの静的表現を配置する
D ::= float l r 発展　浮動小数点定数 ラベル lの位置へ浮動小数点数 rを格納した専用ブロックを配置する
D ::= block l k [ w1, ... , wn] 静的ブロック タグ kと固定フィールドを持つ 読取り専用ブロックをラベル lへ配置する

関数定義の構文

クロージャ中間表現で分離されていた通常の仮引数と自由変数は、 通常の仮引数と環境ポインタへ具体化します。

構文 名称 説明
F ::= function l ( env; x1, ... , xn ) = e 環境付き関数定義 クロージャ環境 envと通常の仮引数を受け取る関数。 クロージャ呼出しの対象になる関数に使用する
F ::= function l ( x1, ... , xn ) = e 環境なし関数定義 クロージャ環境を必要とせず、 直接呼出しだけで使用される関数

大域値定義の構文

構文 名称 説明
G ::= let x = e 大域値定義 低水準式 eを評価し、その結果を大域変数 xへ束縛する

式の構文

低水準中間表現では、通常の値を1ワードで扱います。 変数を x、 1ワード定数を w、 低水準演算を op、 ラベルを l、 ワード単位のオフセットを i で表します。

構文 名称 説明
e ::= w 1ワード定数 タグ付き整数、真偽値、単位値、 引数なしコンストラクタなどを表す64ビット定数
e ::= x 変数 低水準値を保持する局所変数または大域変数
e ::= op( x1, ... , xn) 低水準演算 ワードに対する算術、比較、ビット操作、タグ操作を行う
e ::= let x = e1 in e2 局所定義 e1の結果を xへ束縛してから e2を評価する
e ::= if x then e1 else e2 条件分岐 xが真を表すワードなら e1を、そうでなければ e2を評価する
e ::= switch x with w1 -> e1 | ... | wn -> en | default -> ed ワード値による分岐 xと一致するワード値の分岐を評価する。 一致する値がない場合は省略可能な default分岐を評価する
e ::= alloc x ヒープ確保 xで指定されたワード数の領域を確保し、 先頭アドレスを返す
e ::= load x i メモリの読出し アドレス xから iワード離れた位置を読み出す
e ::= store x i y メモリへの書込み アドレス xから iワード離れた位置へ yを書き込み、単位値を返す
e ::= address_add x i アドレス加算 アドレス xへ iワード分のオフセットを加える
e ::= address_of l ラベルアドレス 関数または静的データのラベル lが指すアドレスを取得する
e ::= call l ( x1, ... , xn) 直接関数呼出し コードラベルlの関数を直接呼び出す
e ::= call_indirect x ( y1, ... , yn) 間接関数呼出し 変数 xが保持するコードアドレスを呼び出す
e ::= runtime_call l ( x1, ... , xn) ランタイム関数呼出し ヒープ確保、文字列操作などを実装する ランタイム関数を呼び出す
e ::= raise x 発展　例外の送出 変数xが表す例外値を送出する
e ::= try e1 with x -> e2 発展　例外処理 例外ハンドラを設定して e1を評価し、 例外発生時は例外値を xへ束縛して e2を評価する
e ::= perform x 発展　エフェクトの実行 変数xが表すエフェクトを実行する

タグ付き整数

ソース言語の整数 nは、次の式でタグ付き整数へ変換します。 

tag_int(n) = (n << 1) | 1
untag_int(w) = w >> 1

最下位ビットが1の値を即値とし、 最下位ビットが0の値をポインタとして扱います。 64ビットのうち1ビットをタグとして使用するため、 通常の整数の範囲は -2^62以上 2^62 - 1以下です。

ソース値 低水準ワード
0 1
1 3
42 85
false 1
true 3
() 1

静的型検査が完了しているため、 整数0、偽、単位値が同じビット表現を使用しても、 実行時に型を取り違えることはありません。

ヒープブロック

ヒープ上の複合値は、1ワードのヘッダと 0個以上のフィールドからなるブロックとして表します。 

+--------+---------+---------+-----+
| header | field 0 | field 1 | ... |
+--------+---------+---------+-----+
             ^
             |
        値として使うポインタ

値として使用するポインタはフィールド0を指します。 ヘッダはポインタの1ワード前、すなわちオフセット -1に置きます。

ヘッダの情報 用途
タグ ヴァリアントのコンストラクタ番号やブロックの種類を表す
サイズ ブロックが持つフィールド数を表す
GC用ビット 発展　GCの世代、色、マーク状態などを保持する

ヘッダを1ワードへまとめる場合は、たとえば下位8ビットをタグ、 残りをサイズおよびGC情報へ割り当てます。 正確なビット配置はVM仕様で定義します。

低水準化

クロージャ中間表現の式 eの低水準化を L⟦e⟧ と表します。 変換中に静的データが必要になった場合は、 新しいラベルを生成してプログラムへ追加します。

プログラム全体の変換

クロージャ中間表現 低水準中間表現 説明
X1 ... Xl F1 ... Fm G1 ... Gn in e 変換中に生成した静的データ、 外部関数宣言、 低水準化した関数定義、 低水準化した大域値定義を並べ、 最後に L⟦e⟧ を置く 各要素を宣言順に変換し、 生成した静的データをプログラムへ追加する

外部関数宣言と大域値定義の変換

クロージャ中間表現 低水準中間表現 説明

相互再帰クロージャ

相互再帰する関数が互いを関数値として参照する場合は、 すべてのクロージャ領域を先に確保し、 その後でヘッダ、コードアドレス、自由変数を初期化します。 この特殊な変換は、クロージャ変換で相互再帰クロージャ群として明示された場合に適用します。

クロージャ中間表現 低水準中間表現 説明
相互参照するクロージャ fと g 
let f_base = alloc f_size in
let g_base = alloc g_size in
let f = address_add f_base 1 in
let g = address_add g_base 1 in
let _ = store f_base 0 f_header in
let _ = store f_base 1 (address_of f_code) in
let _ = store f 1 g in
let _ = store g_base 0 g_header in
let _ = store g_base 1 (address_of g_code) in
let _ = store g 1 f in
...
 確保と初期化を分離して循環参照を構築する。 共有環境方式を採用する場合は、その方式へ統一して変換する

部分適用

部分適用は原則としてクロージャ変換で除去します。 クロージャ中間表現に部分適用が残る設計を採用する場合だけ、 次の変換を適用します。

クロージャ中間表現 低水準中間表現 説明
関数 addへの引数不足の適用 add x 
function partial_add(env; y) =
    let add = load env 1 in
    let x = load env 2 in
    let code = load add 0 in
    call_indirect code (add, x, y)

L⟦make_closure partial_add [add; x]⟧
 与えられた関数と引数を保存し、 残りの引数を受け取る補助クロージャを生成する

ランタイム関数 役割

runtime_equal 複合値を含む構造的等価比較を行う
runtime_string_length 文字列の長さを取得する
runtime_string_get 文字列から文字を取得する
runtime_string_concat 二つの文字列を連結した新しい文字列を作成する

runtime_array_get 発展　範囲検査後に配列要素を読み出す

runtime_callは通常の関数呼出しと区別して保持します。 これにより、GCセーフポイント、外部呼出し規約、 例外送出の可能性を後続段階で明示的に処理できます。

低水準種別

低水準種別 内容 用途
value タグ付き即値またはヒープポインタになり得る言語上の値 通常の値操作、GCルート
word タグなしの64ビット整数 サイズ、ヘッダ、ビット演算、中間計算
address ヒープまたは静的データを指すアドレス ロード、ストア、アドレス計算
code_address 関数コードの先頭を指すアドレス call_indirect
float64 発展　非ボックス化された浮動小数点値 浮動小数点専用命令とレジスタを導入する場合

低水準化で変化しないもの

  • 大域値定義とプログラム本体の評価順序は変更しない
  • letによって明示された左から右の評価順序は保存する
  • 条件分岐とswitchの分岐構造は保存する
  • 関数のコードラベルと引数順序は保存する
  • ブロックのタグ、フィールド数、フィールド順序は保存する
  • 可変ブロックへの書込み順序は保存する
  • 直接呼出しと間接呼出しの区別は保存する
  • 外部関数と外部名の対応は保存する

低水準化後に成立する条件

  • 通常の実行時値が64ビットの1ワードとして表現されている
  • 整数、真偽値、単位値、文字、定数コンストラクタがタグ付き即値へ変換されている
  • 文字列と定数ブロックが静的データまたはヒープブロックへ変換されている
  • タプル、レコード、ヴァリアント、リスト、参照セルが具体的なブロック表現へ変換されている
  • 発展　浮動小数点数が専用の静的データまたはヒープブロックへ変換されている
  • 発展　配列が可変長ブロックとランタイム操作へ変換されている
  • ブロック作成がヒープ確保、ヘッダ書込み、フィールド書込みへ変換されている
  • フィールド読出しがloadへ変換されている
  • フィールド書込みがstoreへ変換されている
  • タグ取得がヘッダ読出しとタグ抽出へ変換されている
  • クロージャがコードアドレスと自由変数を持つヒープブロックへ変換されている
  • クロージャ呼出しがコードアドレスの読出しとcall_indirectへ変換されている
  • 直接呼出しがコードラベルへのcallへ変換されている
  • 環境付き関数が環境ポインタを受け取る
  • 自由変数の取得が環境ポインタからのloadとして明示されている
  • 単純なプリミティブ演算がワード演算へ変換されている
  • 複雑なプリミティブ演算がruntime_callへ変換されている
  • 静的データに一意なラベルが割り当てられている
  • 抽象的なblock、field、setfield、tagが残っていない
  • make_closure、apply_direct、apply_closureが残っていない
  • 各変数にvalue、word、addressなどの低水準種別が付与されている

次の変換との関係

低水準中間表現ではデータ表現とメモリアクセスが具体化されていますが、 式はまだ入れ子構造を持ち、変数は仮想レジスタへ対応付けられていません。

  • 入れ子の式を基本ブロックと制御フローへ変換する
  • 低水準演算を仮想命令セットの命令へ変換する
  • 各一時変数を仮想レジスタへ対応付ける
  • ifとswitchを分岐命令とジャンプへ変換する
  • call、call_indirect、runtime_callを呼出し命令へ変換する
  • 関数ごとの入口ブロック、基本ブロック、終了経路を構築する
  • 生存変数解析とレジスタ割当てに必要な使用・定義情報を明示する
