クロージャ中間表現

K正規形に自由変数解析とクロージャ変換を行い、 関数と、その関数が参照する外側の変数を明示します。

トップレベル関数定義

クロージャ変換後は、関数本体を式の内部に残さず、 トップレベル関数定義としてまとめます。

F ::= トップレベル関数定義
function f ( x1, ... , xn ; z1, ... , zm ) = e 引数と自由変数を持つ関数定義

x1から xnは通常の引数、 z1から zmは自由変数です。

クロージャ中間表現のプログラム

P ::= プログラム
F1 ... Fn; e トップレベル関数定義とメイン式

クロージャ変換の規則

C[e]は、 K正規形の式eをクロージャ変換した結果を表します。

クロージャ変換では、関数本体をトップレベル関数定義へ移動します。 関数が外側の変数を参照する場合は、その自由変数をクロージャへ保存します。

無名関数の変換

無名関数の自由変数を z1、...、 zmとします。 

fun x1 ... xn -> e

次のトップレベル関数定義を生成します。

function f(closure, x1, ..., xn):
    let z1 = field 1 closure in
    ...
    let zm = field m closure in
    C[e]

元の位置にはクロージャ生成を置きます。

make_closure f [z1; ...; zm]

再帰関数定義の変換

各再帰関数の本体をトップレベル関数定義へ移動します。 関数本体から、その関数の名前と仮引数を除いた自由変数を求めます。 

let rec f x1 ... xn = e1 in e2

自由変数が z1、...、 zmの場合、概念的に次へ変換します。 

function f_code(closure, x1, ..., xn):
    let z1 = field 1 closure in
    ...
    let zm = field m closure in
    C[e1]

let f = make_closure f_code [z1; ...; zm] in
C[e2]

既知関数としての変換

関数本体が仮引数と再帰関数名だけを使用し、 外側の自由変数を持たない場合は、クロージャを作成せずに直接呼び出せます。 

let rec add x y = x + y in
add a b

概念的に次へ変換します。

function add(x, y):
    x + y

apply_direct add [a; b]

関数値として使用される既知関数

自由変数を持たない関数でも、その関数自体を値として使用する場合は、 コードアドレスだけを持つクロージャを作成します。 

let rec add x y = x + y in
add

概念的に次へ変換します。

make_closure add []

相互再帰関数の変換

相互再帰する関数群は、一つの集合として自由変数を解析します。 

let rec even n =
    if n = 0 then true else odd (n - 1)
and odd n =
    if n = 0 then false else even (n - 1)
in
even x

evenとoddが外側の自由変数を持たない場合は、 両方をトップレベル関数として直接呼び出せます。 

function even(n):
    ...
    apply_direct odd [n1]

function odd(n):
    ...
    apply_direct even [n1]

apply_direct even [x]

外側の自由変数を持つ場合は、その自由変数を保持するクロージャを作成します。 相互再帰する各関数が互いを値として必要とする場合は、 関数群を同時に初期化できるクロージャ集合として扱います。

直接呼出しの判定

次の条件を満たす呼出しは、apply_directへ変換できます。

  • 呼出し先の関数定義がコンパイル時に判明している
  • 呼出し先に必要な環境をコンパイラが渡せる
  • 呼出し先の関数値が別の値へ置き換えられる可能性がない

それ以外の呼出しは、apply_closureへ変換します。

自由変数

関数の本体で使用される変数のうち、 その関数の引数でも、その関数内で定義された変数でもないものを自由変数と呼びます。 

let make_adder x =
    fun y -> x + y

内側の関数では、yは引数ですが、 xは外側の関数で定義された自由変数です。

クロージャ変換

自由変数を持つ関数を、トップレベルの関数定義とクロージャの作成に分離します。 

let make_adder x =
    fun y -> x + y

上の関数を、次のように変換します。

function add_code(closure, y):
    x = get_free_variable closure 0
    x + y

function make_adder(x):
    make_closure add_code [x]

クロージャには、関数本体のコード位置と自由変数を格納します。 

closure:
    code = add_code
    free_variables = [x]

直接呼出しとクロージャ呼出し

呼出し先の関数がコンパイル時に分かる場合は、関数を直接呼び出します。 

let add x y = x + y in
add 1 2

上の関数適用は、次のようになります。

apply_direct add [1; 2]

呼出し先が実行時に決まる場合は、クロージャを経由して呼び出します。 

let apply f x = f x

上の関数適用は、次のようになります。

apply_closure f [x]

クロージャ変換の結果

クロージャ変換が終わると、局所的な関数定義と無名関数は残りません。 すべての関数本体はトップレベル関数定義へ移動します。

  • 自由変数を持たない既知の関数は直接呼び出す
  • 自由変数を持つ関数はクロージャとして作成する
  • 呼出し先が既知ならapply_directを使用する
  • 呼出し先が実行時に決まるならapply_closureを使用する
  • クロージャへ格納する自由変数は明示的なリストになる

次のデータ表現の具体化では、 make_closureをヒープ確保とフィールド書き込みへ変換し、 apply_closureをコードアドレスの読み出しと間接呼出しへ変換します。
