OCamlをWindowsで使う

OCaml公式のページ ここを見たほうが最新でわかりやすいかも

このサイトで必要なOCaml環境をWindowsに入れる方法について説明します。なお、2026/08/05時点の情報です。

opamというのがOCamlのパッケージマネージャーで、これを入れます。

これまではDiskuv ocamlやwslを使っていましたが、opam2.2以降はwindowsネイティブに入れることができるようになりました。

PowerShellを開いて、Gitとopamを導入します。Gitが既にインストールされているなら、そこは消しててください。

winget install Git.Git OCaml.opam

インストールできたら、一旦PowerShellを全部閉じて、再び開いてください。

opam --version

でバージョンが表示されたら使えるようになっています。

opam init

で初期化します。 ここでコンパイラなどをダウンロードするので時間がかかります。途中でunix環境について質問が来たら、好きなものを選べばいいですが、Cygwinが推奨されるらしいです。これは公式ページも確認してください。終わったら、

(& opam env --switch=default) -split '\\r?\\n' | ForEach-Object { Invoke-Expression $_ }

を実行してください。これで環境が反映されます。

ocaml --version

などで確認してみてください。正しくバージョンが表示されれば成功です。

ocaml

でreplが起動します。例えば

print_endline "Hello, World!";;

とかができます。区切りは;;です。この単位で実行されます。
