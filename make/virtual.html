仮想レジスタ中間表現

低水準中間表現に命令選択、仮想レジスタ化、基本ブロック化を行い、 個数制限のない仮想レジスタを使用する命令列へ変換します。 入れ子になった式は、ラベル、通常命令、終端命令からなる 基本ブロックの集合へ変換します。

  • 低水準中間表現
  • ↓ 命令選択・仮想レジスタ化・基本ブロック化
  • 仮想レジスタ中間表現

この段階では、仮想レジスタを物理レジスタへ割り当てません。 spill位置、スタックフレーム、引数レジスタ、戻り値レジスタなどは、 後続のレジスタ割当てと呼出し規約の具体化で決定します。

プログラムの構文

仮想レジスタ中間表現のプログラムは、 外部関数宣言、静的データ、関数定義から構成されます。 低水準中間表現の大域値定義とプログラム本体は、 特別な global_init関数と main関数へ変換します。

プログラムを P、 外部関数宣言を X、 静的データを D、 関数を F で表します。

構文 名称 説明
P ::= X1 ... Xl D1 ... Dm F1 ... Fn 仮想レジスタプログラム 外部関数宣言、静的データ、 および基本ブロック化された関数定義の集合

外部関数宣言の構文

外部関数宣言は低水準中間表現から引き継ぎます。 実装上は、引数の個数、戻り値の有無、 GCセーフポイントかどうか、例外を送出する可能性などの属性も保持できます。

構文 名称 説明
X ::= external f = name 外部関数宣言 内部ラベル fを、ランタイムまたは外部環境の関数 nameへ対応付ける

静的データの構文

低水準中間表現で生成された静的データは、そのまま保持します。 各ラベルの具体的なアドレスは、 アセンブルまたはリンク時に決定されます。

構文 名称 説明
D ::= string L s 文字列定数 ラベル Lへ文字列 sの静的表現を配置する
D ::= float L r セルフホスト後浮動小数点定数 ラベル Lへ浮動小数点数 rの静的表現を配置する
D ::= block L k [ w1, ... , wn] 静的ブロック タグ kと固定フィールドを持つ 読取り専用ブロックを配置する

関数の構文

関数は、仮想レジスタで表された仮引数、 入口ブロックのラベル、および基本ブロックの集合を持ちます。

構文 名称 説明
F ::= function f ( v1, ... , vn ) entry Lentry { B1 ... Bm } 関数 コードラベル f、 仮引数を表す仮想レジスタ、 入口ブロック、および基本ブロックの集合からなる

環境付き関数では、クロージャ環境を受け取る仮想レジスタも 通常の仮引数列に含めます。 

function add_x(v_env, v_y) entry add_x_entry {
    ...
}

基本ブロックの構文

基本ブロックは、先頭のラベル、0個以上の通常命令、 および1個の終端命令から構成されます。 通常命令の途中から別の基本ブロックへ制御が移動することはありません。

構文 名称 説明
B ::= L: I1 ... In T 基本ブロック ラベル L、 通常命令列、および終端命令からなる

仮想レジスタ

仮想レジスタは、コンパイラが必要な数だけ生成できる一時的な保存場所です。 仮想CPUが持つ有限個の物理レジスタとは異なり、 この段階では個数に制限がありません。 

v0
v1
v2
...

低水準中間表現の変数ごとに仮想レジスタを割り当てます。 一時的な計算結果にも、新しい仮想レジスタを割り当てます。

仮想レジスタ中間表現はSSAではありません。 分岐の合流では、複数の分岐から同じ結果用仮想レジスタへ movすることを許します。 直線的な命令列では、新しい計算結果ごとに新しい仮想レジスタを生成します。

仮想レジスタの種別

種別 内容 主な用途
value タグ付き即値またはヒープポインタになり得る言語上の値 通常の式、GCルート
word タグなし64ビット整数 サイズ、ヘッダ、ビット演算
address データ領域を指すアドレス ロード、ストア、アドレス計算
code_address 関数コードを指すアドレス 間接関数呼出し
float64 セルフホスト後非ボックス化された浮動小数点数 浮動小数点専用レジスタを追加する場合

通常命令の構文

通常命令は、同じ基本ブロック内の次の命令へ制御を移します。 分岐、復帰、末尾呼出しは終端命令として表します。

構文 名称 定義する仮想レジスタ 使用する仮想レジスタ
li vd, w ワード即値の読込み vd なし
la vd, L ラベルアドレスの読込み vd なし
mov vd, vs 値のコピー vd vs
binop vd, v1, v2 二項演算 vd v1、 v2
unop vd, vs 単項演算 vd vs
binopi vd, vs, i 即値付き二項演算 vd vs
load vd, i(vb) メモリの読出し vd vb
store vs, i(vb) メモリへの書込み なし vs、 vb
load_global vd, g 大域値の読出し vd なし
store_global g, vs 大域値への書込み なし vs
call vd, f ( v1, ... , vn) 直接関数呼出し vd v1から vn
callr vd, vf ( v1, ... , vn) 間接関数呼出し vd vf、 v1から vn
runtime_call vd, f ( v1, ... , vn) ランタイム関数呼出し vd v1から vn

値を返さない関数については、宛先仮想レジスタを省略できます。 

runtime_call runtime_print_int(v0)

演算命令

分類 命令 説明
算術演算 add、 sub、 mul、 div、 rem 64ビットワードの加算、減算、乗算、除算、剰余
ビット演算 and、 or、 xor、 not 論理積、論理和、排他的論理和、ビット反転
シフト shl、 shr、 sar 左シフト、論理右シフト、算術右シフト
比較 seq、 sne、 slt、 sle、 sgt、 sge 言語上の真偽値を表すタグ付きワードを生成する
即値演算 addi、 andi、 ori、 xori、 shli、 shri、 sari 第2オペランドとして即値を使用する演算

メモリ命令のオフセット

loadと storeのオフセットはワード単位です。 1ワードが8バイトの場合、 オフセット2は実アドレス上の16バイトに対応します。 バイト単位への変換は最終命令を生成する段階で行います。

終端命令の構文

各基本ブロックは、必ず一つの終端命令で終了します。 終端命令の後ろに通常命令を置くことはできません。

構文 名称 使用する仮想レジスタ 後続ブロック
jump L 無条件分岐 なし L
branch v, Ltrue, Lfalse 条件分岐 v Ltrueと Lfalse
switch v [ w1: L1, ... , default: Ld ] 多方向分岐 v 各分岐先と省略可能な既定分岐先
return v 関数からの復帰 v なし
tailcall f ( v1, ... , vn) 直接末尾呼出し v1から vn なし
tailcallr vf ( v1, ... , vn) 間接末尾呼出し vf、 v1から vn なし
halt v プログラムの停止 v なし
raise v セルフホスト後例外の送出 v 通常の後続ブロックを持たない

制御フローグラフ

基本ブロックを頂点とし、 終端命令が指定する移動先を有向辺とするグラフを 制御フローグラフと呼びます。 制御フローグラフは独立した構文ではなく、 関数内の基本ブロックと終端命令から構築します。

終端命令 後続ブロック集合
jump L {L}
branch v, L1, L2 {L1, L2}
switch すべての分岐先ラベルの集合
return、 tailcall、 tailcallr、 halt 空集合

命令選択と基本ブロック化

低水準中間表現から仮想レジスタ中間表現への変換には、 非末尾位置の変換と末尾位置の変換を使用します。

記法 意味
V⟦ e, vd ⟧ 式 eを非末尾位置として変換し、 結果を vdへ格納する
VT⟦ e ⟧ 式 eを関数本体の末尾位置として変換し、 復帰または末尾呼出しを生成する
VM⟦ e ⟧ プログラム本体 eを mainの末尾位置として変換し、 最後に haltを生成する

変換は、命令列だけでなく、 現在の基本ブロックと新しく生成した基本ブロックの集合も更新します。 vxは、 低水準中間表現の変数 xに対応する仮想レジスタです。

プログラム全体の変換

低水準中間表現 仮想レジスタ中間表現 説明
X1 ... Xl D1 ... Dm F1 ... Fn G1 ... Gp in e 外部関数宣言と静的データを保持し、 各関数定義を変換する。 大域値定義から global_initを生成し、 プログラム本体から mainを生成する 低水準プログラムを、 静的データと基本ブロック化された関数の集合へ変換する

外部関数宣言と静的データの変換

低水準中間表現 仮想レジスタ中間表現 説明
external f = name external f = name 外部関数宣言をそのまま保持する
string L s string L s 文字列定数とラベルをそのまま保持する
float L r float L r セルフホスト後浮動小数点定数とラベルをそのまま保持する
block L k [ w1, ... , wn] 同じラベル、タグ、フィールドを持つ静的ブロック 静的ブロックをそのまま保持する

関数定義の変換

低水準中間表現 仮想レジスタ中間表現 説明
function f ( x1, ... , xn ) = e 
function f(v_x1, ..., v_xn) entry L_entry {
L_entry:
    VT⟦e⟧
}
 各仮引数へ仮想レジスタを割り当て、 新しい入口ブロックから関数本体の末尾位置変換を開始する

大域値初期化の変換

低水準中間表現 仮想レジスタ中間表現 説明
大域値定義がない場合 
function global_init() entry init_entry {
init_entry:
    li v_unit, unit_value
    return v_unit
}
 単位値を返す空の初期化関数を生成する。 実装ではこの関数自体を省略してもよい
let g1 = e1 ... let gn = en 
function global_init() entry init_entry {
init_entry:
    V⟦e1, v_g1⟧
    store_global g1, v_g1
    ...
    V⟦en, v_gn⟧
    store_global gn, v_gn
    li v_unit, unit_value
    return v_unit
}
 大域値の初期化式を宣言順に評価し、 各結果を対応する大域領域へ保存する

呼出し命令の性質

この段階では、関数の引数と戻り値を仮想レジスタで表します。 物理的な引数レジスタ、戻り値レジスタ、 スタック引数への具体的な配置はまだ決定しません。 

call v_result, add(v_left, v_right)

呼出し命令は、一部の物理レジスタを破壊する可能性があります。 破壊される物理レジスタの集合は呼出し規約で決定し、 レジスタ割当て時に考慮します。

末尾呼出しの性質

末尾呼出しは、現在の関数へ戻る必要がない関数呼出しです。 仮想レジスタ中間表現では終端命令として表します。 

tailcall loop(v_state, v_input)

後続のコード生成では、現在のスタックフレームを破棄または再利用し、 呼出し先へのジャンプとして実装します。 引数を安全に並べ替えられない場合は、 一時領域を使用して並行コピーを解決します。

生存変数解析に必要な情報

後続のレジスタ割当てでは、 各命令の定義集合と使用集合を使用します。

命令 定義集合 使用集合
add vd, v1, v2 {vd} {v1, v2}
load vd, i(vb) {vd} {vb}
store vs, i(vb) ∅ {vs, vb}
load_global vd, g {vd} ∅
store_global g, vs ∅ {vs}
call vd, f(v1, ..., vn) {vd} {v1, ..., vn}
callr vd, vf(v1, ..., vn) {vd} {vf, v1, ..., vn}
branch v, L1, L2 ∅ {v}
return v ∅ {v}
tailcall f(v1, ..., vn) ∅ {v1, ..., vn}

基本ブロックの use集合は、ブロック内で定義される前に使用される 仮想レジスタの集合です。 def集合は、ブロック内で定義される 仮想レジスタの集合です。

命令選択で変化しないもの

  • 外部関数宣言と外部名の対応は変更しない
  • 静的データの内容とラベルは変更しない
  • 関数の引数順序は変更しない
  • 低水準中間表現で確定した値表現は変更しない
  • ワード単位のメモリ配置とフィールド順序は変更しない
  • 直接呼出し、間接呼出し、ランタイム呼出しの区別は変更しない
  • letで明示された評価順序は命令順序として保存する
  • 条件分岐とswitchの意味は制御フローとして保存する
  • 末尾位置にある呼出しは末尾呼出しとして保存する

変換後に成立する条件

  • すべての関数が基本ブロックの集合へ変換されている
  • プログラム本体がmain関数へ変換されている
  • 大域値の初期化が宣言順に実行されるglobal_initへ変換されている
  • 各関数に一つの入口ブロックが存在する
  • 各基本ブロックは一つのラベルを持つ
  • 各基本ブロックは0個以上の通常命令と一つの終端命令を持つ
  • 終端命令の後ろに通常命令が存在しない
  • すべての分岐先ラベルが同じ関数内の基本ブロックを指している
  • 低水準中間表現の局所変数が仮想レジスタへ対応付けられている
  • 大域変数の参照と初期化がload_globalとstore_globalで明示されている
  • 一時的な計算結果が仮想レジスタへ格納されている
  • 仮想レジスタにvalue、word、addressなどの種別が付与されている
  • 低水準演算が仮想命令セットの命令へ変換されている
  • メモリ操作がloadとstoreへ変換されている
  • ヒープ確保がruntime_allocの呼出しへ変換されている
  • 条件式がbranchと基本ブロックへ変換されている
  • switchが多方向分岐と基本ブロックへ変換されている
  • 直接呼出しがcallへ変換されている
  • 間接呼出しがcallrへ変換されている
  • ランタイム呼出しがruntime_callとして区別されている
  • 末尾位置の直接呼出しがtailcallへ変換されている
  • 末尾位置の間接呼出しがtailcallrへ変換されている
  • 静的データとコードラベルが具体的なアドレスへ変換されず、ラベルのまま保持されている
  • まだ物理レジスタ、spillスロット、スタックフレームの配置は決定されていない
  • セルフホスト後配列操作がランタイム関数の呼出しへ変換されている

次の変換との関係

次のレジスタ割当てでは、制御フローグラフを使用して 各仮想レジスタの生存範囲を計算します。 同時に生存する仮想レジスタを同じ物理レジスタへ割り当てないようにし、 物理レジスタへ収まらない値をスタックスロットへspillします。

  • 各命令と基本ブロックの使用集合・定義集合を求める
