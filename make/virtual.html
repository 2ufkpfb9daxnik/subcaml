仮想レジスタ中間表現

低水準中間表現に命令選択と基本ブロック化を行い、 仮想レジスタを使用する命令列へ変換します。

  • 低水準中間表現
    ↓ 命令選択・基本ブロック化
  • 仮想レジスタ中間表現

仮想レジスタ

仮想レジスタは、コンパイラが必要なだけ生成できる一時的なレジスタです。 仮想CPUが持つ16本の物理レジスタとは異なり、個数に制限はありません。 

v0
v1
v2
...

低水準中間表現の変数と一時的な計算結果を、 仮想レジスタへ対応させます。 

let z = add (x, y) in
mul (z, z)

    ↓

add v2, v0, v1
mul v3, v2, v2

命令選択と基本ブロック化の規則

V[e, vd]は、 低水準中間表現の式eを評価し、 結果を仮想レジスタvdへ格納する 命令列を表します。

条件分岐やswitchでは新しい基本ブロックを生成します。 vxは変数 xに対応する仮想レジスタを表します。

プログラム全体の変換

低水準中間表現 仮想レジスタ中間表現
D1 ... Dn; F1 ... Fm; e 静的データ D1 ... Dnと、 変換した関数 V[F1] ... V[Fm]、 メイン式から生成したmain関数

関数定義の変換

低水準中間表現 仮想レジスタ中間表現
function f (x1, ... , xn) = e function f (v1, ... , vn) {
Lentry:
V[e, vresult]
return vresult
}

式の変換

低水準中間表現 仮想レジスタ中間表現
w li vd, w
x mov vd, vx

V[e2, vd]
op (x1, ... , xn) op vd, vx₁, ... , vxₙ
if x then e1 else e2 branch vx, Lthen, Lelse

Lthen:
V[e1, vd]
jump Ljoin

Lelse:
V[e2, vd]
jump Ljoin

Ljoin:
switch x with w1 -> e1 | ... | wn -> en switch vx [ w1: L1, ... , wn: Ln ]

各iについて、
Li:
V[ei, vd]
jump Ljoin

Ljoin:
alloc x runtime_call vd, runtime_alloc( vx)
load x i load vd, i( vx)
store x i y store vy, i( vx)

address_add x i addi vd, vx, i
address_of L la vd, L

runtime_call f (x1, ... , xn) runtime_call vd, f (vx₁, ... , vxₙ)
raise x raise vx

末尾位置の変換

関数本体の末尾位置では、呼出し結果を一時レジスタへ受け取って returnする代わりに、末尾呼出しを生成します。

低水準中間表現の末尾式 仮想レジスタ中間表現
call f (x1, ... , xn) tailcall f (vx₁, ... , vxₙ)
call_indirect x (y1, ... , yn) tailcallr vx (vy₁, ... , vyₙ)
それ以外のe V[e, vresult]
return vresult

命令選択

低水準中間表現の演算を、仮想CPUの命令に近い命令へ変換します。 この段階では、命令のオペランドに仮想レジスタを使用します。

低水準中間表現 仮想レジスタ命令
x + y add vd, vx, vy
x - y sub vd, vx, vy
x * y mul vd, vx, vy
load x i load vd, i(vx)
store x i y store vy, i(vx)
address_of L la vd, L
call f (x1, ..., xn) call vd, f (v1, ..., vn)
call_indirect f (x1, ..., xn) callr vd, vf (v1, ..., vn)

基本ブロック化

式の木構造を、命令列と分岐からなる基本ブロックの集合へ変換します。

基本ブロックは、先頭にラベルを持ち、 途中に分岐を含まない命令列です。 各基本ブロックの最後には、必ず終端命令を置きます。 

if v0 then
    v1 + v2
else
    v1 - v2

    ↓

entry:
    branch v0, then_block, else_block

then_block:
    add v3, v1, v2
    jump end_block

else_block:
    sub v3, v1, v2
    jump end_block

end_block:
    return v3

制御フローグラフ

基本ブロックを頂点とし、終端命令による移動先を辺とするグラフを、 制御フローグラフと呼びます。

制御フローグラフは独立した中間表現ではなく、 仮想レジスタ中間表現に含まれる基本ブロックと終端命令から得られます。

プログラム

P ::= 仮想レジスタプログラム
D1 ... Dn; F1 ... Fm 静的データと関数定義

静的データ

低水準中間表現の静的データは、そのまま保持します。 ラベルは後のアセンブリ出力とアセンブルによって具体的なアドレスへ変換されます。

D ::= 静的データ
string L s 文字列定数
float L r 浮動小数点定数
block L [w1, ... , wn] 静的ブロック

関数

F ::= 関数
function f (v1, ... , vn) { B1 ... Bm } 基本ブロックの集合からなる関数

関数の仮引数も仮想レジスタとして扱います。 引数を物理レジスタやスタックへ配置する処理は、 後のレジスタ割当てとコード生成で行います。

基本ブロック

B ::= 基本ブロック
L: I1 ... In T ラベル、通常命令列、終端命令

通常命令

I ::= 通常命令
li vd, i 整数即値の読み込み
la vd, L ラベルアドレスの読み込み
mov vd, vs 値のコピー
add vd, v1, v2 加算
sub vd, v1, v2 減算
mul vd, v1, v2 乗算
div vd, v1, v2 除算
rem vd, v1, v2 剰余
addi vd, vs, i 即値加算
bitop vd, v1, v2 ビット演算
cmp vd, v1, v2 比較
load vd, i(vb) メモリの読み出し
store vs, i(vb) メモリへの書き込み
call vd, f (v1, ... , vn) 直接関数呼出し
callr vd, vf (v1, ... , vn) 間接関数呼出し
runtime_call vd, f (v1, ... , vn) ランタイム関数呼出し

bitopには、and、or、 xor、shl、shr、 sarが入ります。

cmpには、seqと sltが入ります。 その他の比較は、これらの命令とビット演算または分岐の組合せへ変換します。

終端命令

T ::= 終端命令
jump L 無条件分岐
branch v, L1, L2 条件分岐
switch v [ i1: L1, ... , in: Ln ] 整数値による多方向分岐
return v 関数からの復帰
tailcall f (v1, ... , vn) 直接末尾呼出し
tailcallr vf (v1, ... , vn) 間接末尾呼出し
halt プログラムの停止
raise v 発展　例外の送出

関数呼出し

この段階では、関数の引数と戻り値を仮想レジスタとして表します。 物理レジスタやスタックへの具体的な配置は、レジスタ割当て後に行います。 

call v3, add(v1, v2)

上の命令は、addへv1とv2を渡し、 戻り値をv3へ格納することを表します。

クロージャ呼出し

クロージャ呼出しでは、低水準化によって読み出されたコードアドレスと、 クロージャ自身を含む引数を使用します。 

load  v2, 0(v1)
callr v3, v2(v1, v4)

v1はクロージャ、 v2はコードアドレス、 v4は通常の引数です。

末尾呼出し

関数本体の最後にある直接呼出しと間接呼出しは、 末尾呼出しとして表します。 

tailcall loop(v1, v2)

末尾呼出しは、後のコード生成で現在のスタックフレームを再利用し、 callではなくジャンプへ変換します。

条件分岐の変換

低水準中間表現の次の式を考えます。

if x then
    e1
else
    e2

仮想レジスタ中間表現では、次の基本ブロックへ変換します。

entry:
    branch vx, then_block, else_block

then_block:
    e1
    jump end_block

else_block:
    e2
    jump end_block

end_block:
    ...

分岐式の結果を後続の処理で使用する場合、 両方の分岐で同じ結果用仮想レジスタを定義します。 

then_block:
    mov v_result, v_then
    jump end_block

else_block:
    mov v_result, v_else
    jump end_block

switchの変換

低水準中間表現のswitchは、 複数の基本ブロックへの分岐へ変換します。 

entry:
    switch v0 [
        0: case_0,
        1: case_1,
        2: case_2
    ]

case_0:
    ...
    jump end_block

case_1:
    ...
    jump end_block

case_2:
    ...
    jump end_block

分岐数が少ない場合は比較と条件分岐の列へ変換し、 分岐数が多い場合はジャンプテーブルとして実装できます。

ヒープ確保の変換

低水準中間表現のallocは、 ランタイム関数呼出しへ変換します。 

let p = alloc size in e

    ↓

runtime_call vp, runtime_alloc(v_size)
...

戻り値として、確保された領域の先頭アドレスを受け取ります。

メイン式

低水準中間表現のメイン式は、特別な関数mainへ変換します。 

function main() {
entry:
    ...
    halt
}

mainはプログラムのエントリポイントになります。

仮想レジスタ中間表現の性質

  • 仮想レジスタは必要な数だけ生成できる
  • 関数は基本ブロックの集合として表される
  • 各基本ブロックはラベル、通常命令列、終端命令を持つ
  • 制御フローはジャンプと分岐として明示される
  • 関数呼出しの引数と戻り値は仮想レジスタで表される
  • 直接呼出し、間接呼出し、末尾呼出しを区別する
  • ヒープ確保や外部処理はランタイム関数呼出しとして表される
  • まだ物理レジスタ、spill位置、スタックフレームは決まっていない

次のレジスタ割当てとコード生成では、 仮想レジスタの生存範囲を解析し、 各仮想レジスタを物理レジスタまたはスタックスロットへ割り当てます。
