K正規形

K正規化は、コア中間表現に含まれる計算結果へ名前を付け、 プリミティブ演算、関数適用、ブロック操作、分岐条件などのオペランドを変数へ限定する変換です。 変換後の中間表現をK正規形と呼びます。

入力変換出力
型付きコア中間表現K正規化型付きK正規形

元の式の評価順序は、letの入れ子として明示します。 関数部分、実引数、演算の引数、ブロックのフィールドは、コア中間表現と同じく左から右へ評価します。

プログラムと大域宣言

構文名称説明
P ::= d1 ... dn in eプログラム大域宣言を順番に初期化して本体を評価する
d ::= let x = e大域値定義式の結果を大域変数へ束縛する
d ::= let rec f1 x11 ... = e1 and ...大域再帰関数定義一つ以上の相互再帰関数を定義する
d ::= external f = name外部関数宣言内部識別子と外部名を対応付ける

式

構文名称オペランド制約
e ::= c定数なし
e ::= x変数なし
e ::= op(x1, ... ,xn)プリミティブ演算すべて変数
e ::= if x then e1 else e2条件分岐条件は変数

e ::= let rec ... in e局所再帰関数定義仮引数は変数、各本体はK正規形
e ::= fun x1 ... xn -> e関数仮引数は変数、本体はK正規形

K正規化の記法

記法意味
K⟦e⟧式eをK正規化した式
KD⟦d⟧大域宣言dをK正規化した宣言
KP⟦P⟧プログラム全体をK正規化したプログラム
bind e as x in EeをK正規化し、その結果を変数xとして後続式Eへ渡す補助操作
fresh(T)型Tを持つ新しい一意な一時変数を生成する

bindの定義

K正規化結果bind e as x in Eの結果説明
K⟦e⟧ = yE[y/x]結果が既存変数なら不要なletを作らない
K⟦e⟧ = e'かつe'が変数でないlet x:T = e' in E式の型Tを付けた一時変数へ束縛する

E[y/x]は、補助変数xの自由な出現をyへ置換することを表します。 実装では構文木を後から置換するより、継続を受け取る関数としてbindを実装すると単純です。

条件分岐の変換

コア中間表現K正規形評価規則
if e1 then e2 else e3bind e1 as x in if x then K⟦e2⟧ else K⟦e3⟧条件だけを先に評価し、選ばれた分岐だけを実行時に評価する

分岐式を条件より前へ移動してはなりません。 K正規化は制御構造を保ったまま、各分岐の内部だけを再帰的に変換します。

変換時に禁止する移動

境界禁止する変換理由
if分岐内の計算を条件分岐の前へ出す実行されない分岐の副作用が発生するため
switchcase内の計算を判定前へ出す選択されないcaseを評価してしまうため
try保護式内の計算をtryの外へ出す例外が捕捉されなくなるため
performエフェクトを他の副作用より前後へ移動するハンドラが観測する順序が変わるため
関数適用実引数の評価順序を入れ替える左から右の評価順序を保持するため

K正規化で変化しないもの

対象保持する性質
大域宣言宣言順序

制御構造条件分岐、switch、例外境界
ブロックタグ、フィールド数、フィールド順序
型各式、変数、関数の型

K正規化後に成立する条件

分類条件
適用関数部分とすべての実引数が変数である
プリミティブすべてのオペランドが変数である
条件分岐条件が変数である
switch判定対象が変数である
ブロック作成すべてのフィールド値が変数である
フィールド読出し対象が変数である
フィールド書込み対象と値が変数である
タグ読出し対象が変数である
例外とエフェクトraiseとperformの引数が変数である
一時変数すべて一意な識別子と正しい型を持つ
評価順序元の左から右の順序がletの順序として表現されている
構文すべての大域初期化式と関数本体が同じ条件を再帰的に満たす
Core整合性Core変換で除去したパターン、match、型宣言、モジュール構文を再導入していない

型付き一時変数値表現と後続の低水準化を選択できる
