K正規形

コア中間表現に含まれる各部分式の結果へ名前を付け、 プリミティブ演算、関数適用、ブロック操作などのオペランドを変数へ限定します。 この変換をK正規化と呼び、変換後の中間表現をK正規形と呼びます。

  • コア中間表現
  • ↓ K正規化
  • K正規形

K正規化では、元の式の評価順序を letによる局所定義の順序として明示します。 ソース言語の評価順序と同様に、関数部分、実引数、プリミティブ演算の引数、 ブロックのフィールドなどは左から右へ評価します。

プログラムと大域宣言の構文

K正規形のプログラムは、大域宣言の列とプログラム本体から構成されます。 プログラムを P、 大域宣言を d、 式を e で表します。

構文 名称 説明
P ::= d1 ... dn in e プログラム 大域宣言 d1から dnを宣言順に初期化し、 本体式 eを評価する
d ::= let x = e 大域値定義 式 eを評価し、その結果を大域変数 xへ束縛する
d ::= let rec f1 x11 ... x1m₁ = e1 and ... and fn xn1 ... xnmₙ = en 大域再帰関数定義 一つ以上の大域的な相互再帰関数を定義する。 各関数の仮引数は変数だけで構成される
d ::= external f = name 外部関数宣言 大域識別子 fを、ランタイムまたは外部環境の関数 nameへ対応付ける

式の構文

定数を c、 変数を x、 プリミティブ演算を op、 ブロックタグまたは switchの比較値を k で表します。

構文 名称 説明
e ::= c 定数 整数、浮動小数点数、真偽値、文字、文字列、 unitなどの定数
e ::= x 変数 名前解決済みの局所変数または大域変数
e ::= op( x1, ... , xn) プリミティブ演算 変数 x1から xnをオペランドとして、 算術、比較、配列操作などのプリミティブ演算を実行する
e ::= if x then e1 else e2 条件分岐 変数 xが真なら e1を、偽なら e2を評価する
e ::= let x = e1 in e2 局所定義 e1の結果を xへ束縛し、 e2を評価する
e ::= let rec f1 x11 ... x1m₁ = e1 and ... and fn xn1 ... xnmₙ = en in e 局所再帰関数定義 一つ以上の局所的な相互再帰関数を定義してから eを評価する
e ::= fun x1 ... xn -> e 関数 仮引数 x1から xnを受け取り、 本体 eを評価する関数を作成する
e ::= f x1 ... xn 関数適用 変数 fが表す関数へ、変数 x1から xnを渡す
e ::= block k ( x1, ... , xn) ブロックの作成 タグ kと、変数 x1から xnの値をフィールドとして持つ ブロックを作成する
e ::= field i x フィールドの読み出し 変数 xが表すブロックの i番目のフィールドを読み出す
e ::= setfield i x y フィールドへの書き込み 変数 xが表す可変ブロックの i番目のフィールドへ yの値を書き込み、 unitを返す
e ::= tag x タグの読み出し 変数 xが表すブロックのタグを読み出す
e ::= switch x with k1 -> e1 | ... | kn -> en | default -> ed 整数またはタグによる分岐 変数 xの値と一致する分岐を評価する。 どの値にも一致しない場合は、省略可能な default分岐を評価する
e ::= raise x 例外の送出 セルフホスト後変数 xが表す例外値を送出する
e ::= try e1 with x -> e2 例外処理 セルフホスト後 e1から送出された例外を xへ束縛し、 e2で処理する
e ::= perform x エフェクトの実行 セルフホスト後変数 xが表すエフェクトを実行する

型情報

上の構文では表記を簡潔にするため型を省略していますが、 実装上は大域変数、局所変数、関数の仮引数、関数の戻り値、 およびK正規化によって生成した一時変数の型を保持します。 新しい一時変数には、その変数へ束縛する部分式の型を付与します。

型情報は、整数演算と浮動小数点演算の区別、 値の実行時表現の決定、外部関数の呼出し、 後続の低水準化などで利用します。

K正規化

コア中間表現では、プリミティブ演算や関数適用のオペランドとして、 任意の式を記述できます。 

f (int_add(x, 1)) (g y)

K正規化では、各部分式の結果を新しい一時変数へ束縛します。 

let one = 1 in
let a = int_add(x, one) in
let b = g y in
f a b

この変換により、プリミティブ演算、関数適用、ブロック操作などが使用する値を、 すべて変数として明示できます。

K正規化の補助操作

式 eをK正規化した結果を、 K⟦e⟧ と表します。 K正規化した部分式の結果を変数として後続の変換へ渡すため、 補助操作 bindを使用します。 

bind e as x in E

K⟦e⟧ が既存の変数 yである場合は、新しい letを生成せず、後続の式 Eで xの代わりに yを使用します。 

K⟦e⟧ = y の場合:

bind e as x in E
    = E[y/x]

K⟦e⟧ が変数でない場合は、その結果を新しい変数 xへ束縛します。 

K⟦e⟧ = e' かつ e' が変数でない場合:

bind e as x in E
    = let x = e' in E

E[y/x]は、後続の式 Eに現れる補助変数 xを、既存の変数 yへ置換することを表します。 K正規化によって新しく生成する変数は、 既存のどの変数とも重複しないものとします。

定数もプリミティブ演算などのオペランドへ直接置かず、 新しい変数へ束縛します。 したがって、このK正規形ではプリミティブ演算、 関数適用、ブロック操作のオペランドは例外なく変数になります。

プログラムと大域宣言のK正規化

プログラム全体のK正規化を KP⟦P⟧、 大域宣言のK正規化を KD⟦d⟧ と表します。

コア中間表現 K正規形 説明
d1 ... dn in e KD⟦d1⟧ ... KD⟦dn⟧ in K⟦e⟧ 各大域宣言を宣言順にK正規化し、 最後にプログラム本体をK正規化する
let x = e let x = K⟦e⟧ 大域値の初期化式をK正規化する
let rec f1 x11 ... x1m₁ = e1 and ... and fn xn1 ... xnmₙ = en let rec f1 x11 ... x1m₁ = K⟦e1⟧ and ... and fn xn1 ... xnmₙ = K⟦en⟧ 各関数の本体を独立にK正規化する
external f = name external f = name 外部関数宣言は評価対象となる式を含まないため、そのまま残す

式のK正規化

複数の部分式を持つ構文では、部分式を左から右へK正規化します。 表中の x、 x1から xn、 および fは、必要に応じて新しく生成する変数を表します。

コア中間表現 K正規形 説明
c c 定数をそのまま残す
x x 変数をそのまま残す
op( e1, ... , en) bind e1 as x1 in
...
bind en as xn in
op( x1, ... , xn)
各オペランドを左から右へK正規化し、 変数だけをプリミティブ演算へ渡す
if e1 then e2 else e3 bind e1 as x in
if x then K⟦e2⟧ else K⟦e3⟧
条件式を変数へ束縛し、 真分岐と偽分岐を独立にK正規化する
let x = e1 in e2 let x = K⟦e1⟧ in K⟦e2⟧ 束縛される式と let本体をそれぞれK正規化する
let rec f1 x11 ... x1m₁ = e1 and ... and fn xn1 ... xnmₙ = en in e let rec f1 x11 ... x1m₁ = K⟦e1⟧ and ... and fn xn1 ... xnmₙ = K⟦en⟧ in K⟦e⟧ 各関数本体と let recの後続式を独立にK正規化する
fun x1 ... xn -> e fun x1 ... xn -> K⟦e⟧ 関数本体をK正規化する
e e1 ... en bind e as f in
bind e1 as x1 in
...
bind en as xn in
f x1 ... xn
関数部分を最初に評価し、 その後で各実引数を左から右へ評価する。 関数部分とすべての実引数を変数に限定する
block k ( e1, ... , en) bind e1 as x1 in
...
bind en as xn in
block k ( x1, ... , xn)
各フィールドを左から右へ評価し、 変数だけをブロックへ格納する
field i e bind e as x in
field i x
ブロックを表す式を変数へ束縛してから、 指定されたフィールドを読み出す
setfield i e1 e2 bind e1 as x in
bind e2 as y in
setfield i x y
ブロックを表す式と書き込む値を左から右へ評価し、 両方を変数へ限定する
tag e bind e as x in
tag x
ブロックを表す式を変数へ束縛してからタグを読み出す

k1 -> K⟦e1⟧
...
kn -> K⟦en⟧
| default -> K⟦ed⟧

セルフホスト後例外値を変数へ束縛してから送出する

perform x

変換例

プリミティブ演算

int_add(x, int_mul(y, z))

内側の乗算結果を変数へ束縛してから、外側の加算を実行します。 

let a = int_mul(y, z) in
int_add(x, a)

式全体の結果も明示的な変数へ束縛する必要がある後続の文脈では、 さらに次のようになります。 

let a = int_mul(y, z) in
let b = int_add(x, a) in
b

定数を含むプリミティブ演算

int_add(x, 1)

このK正規形ではプリミティブ演算のオペランドを変数に限定するため、 定数も一度変数へ束縛します。 

let one = 1 in
int_add(x, one)

条件分岐

if lt(int_add(x, 1), y) then
    f x
else
    g y

条件式を構成する各部分式を左から右へ評価し、 条件分岐の判定対象を変数へ限定します。 

let one = 1 in
let a = int_add(x, one) in
let condition = lt(a, y) in
if condition then
    f x
else
    g y

関数適用

f (g x) (h y)

関数部分を最初に評価し、その後で実引数を左から右へ評価します。 この例では関数部分 fはすでに変数なので、新しい束縛は生成しません。 

let a = g x in
let b = h y in
f a b

関数部分自体が式である場合も、その結果を変数へ束縛します。 

(if condition then f else g) x
let function_value =
    if condition then
        f
    else
        g
in
function_value x

ブロックの作成

block 0 (f x, int_add(y, 1))

ブロックの各フィールドを左から右へ評価し、 各結果を変数へ束縛してからブロックを作成します。 

let a = f x in
let one = 1 in
let b = int_add(y, one) in
block 0 (a, b)

フィールドへの書き込み

setfield 0 (make_ref x) (f y)

書込み対象を先に評価し、その後で書き込む値を評価します。 

let reference = make_ref x in
let value = f y in
setfield 0 reference value

タグによる分岐

switch tag (f x) with
| leaf_tag -> 0
| node_tag -> 1
| default -> match_failure()

関数適用の結果とタグの読み出し結果を、それぞれ変数へ束縛します。 各分岐も独立にK正規化します。 

let value = f x in
let value_tag = tag value in
switch value_tag with
| leaf_tag ->
    0
| node_tag ->
    1
| default ->
    match_failure()

K正規化で生成する一時変数

K正規化で生成する各一時変数には、一意な内部識別子と型を割り当てます。 表示上の名前が同じであっても、内部識別子が異なれば別の変数として扱います。

実装では、たとえば次のような情報を保持できます。 

type id = {
    name : string;
    unique : int;
}

type binding = {
    id : id;
    typ : typ;
}

新しい変数名は、人間が読む表示では tmp1、 tmp2などとしても構いません。 コンパイラ内部では連番などによって必ず一意性を保証します。

K正規化で変化しないもの

  • 大域宣言の順序は変更しない
  • 局所定義のスコープは変更しない
  • 関数の仮引数と戻り値の型は変更しない
  • 相互再帰関数の相互参照関係は変更しない
  • 条件分岐とswitchの分岐構造は変更しない
  • ブロックのタグ、フィールド数、フィールド順序は変更しない
  • 副作用を伴う式の評価順序は変更しない
  • 外部関数と外部名の対応は変更しない

K正規化後に成立する条件

  • プログラム本体とすべての大域値の初期化式がK正規形になっている
  • 局所関数と大域関数を含むすべての関数本体がK正規形になっている
  • プリミティブ演算のすべてのオペランドが変数である
  • 関数適用の関数部分とすべての実引数が変数である
  • ブロックへ格納するすべてのフィールド値が変数である
  • フィールドの読み出し対象が変数である
  • フィールドへの書込み対象と書き込む値が変数である
  • タグの読み出し対象が変数である
  • 条件分岐の判定対象が変数である
  • switchの判定対象が変数である
  • raiseおよびperformの引数が変数である
  • 複雑な部分式の結果がletで束縛されている
  • 元の式の左から右の評価順序がletの順序として明示されている
  • K正規化によって生成された一時変数が一意な識別子を持っている
  • K正規化によって生成された一時変数に対応する部分式の型が付与されている
  • パターン、match式、型宣言、モジュール宣言など、Coreへの変換で除去された構文は再び導入されていない

次の変換との関係

K正規形では、計算の各段階と値の受け渡しが変数によって明示されます。 次のクロージャ変換では、それぞれの関数について自由変数を計算し、 関数のコードと自由変数を保持する環境を明示します。

関数適用の関数部分と実引数がすでに変数へ限定されているため、 クロージャ変換では、通常の関数適用を直接呼出しまたはクロージャ呼出しへ 比較的単純に分類できます。
