K正規形

コア中間表現の各部分式に名前を付け、 プリミティブ演算や関数適用の引数を変数に限定します。

  • コア中間表現
    ↓ K正規化
  • K正規形

K正規化

コア中間表現では、演算や関数適用の中に任意の式を記述できます。 

f (x + 1) (g y)

K正規化では、各部分式の結果を一時変数へ束縛します。 

let i = 1 in
let a = x + i in
let b = g y in
f a b

この変換により、演算や関数適用が使用する値を、 すべて変数として明示できます。

K正規化の規則

K[e]は、 式eをK正規化した結果を表します。 次の補助記法を使用します。 

bind e as x in e'
    = K[e]が変数なら、その変数をxとしてe'を続ける
    = それ以外なら、let x = K[e] in e'を生成する

複数の部分式は左から右へ処理します。 表中のx、x1、...は 新しく生成する変数を表します。

変換例

プリミティブ演算

x + (y * z)

上の式を、次のように変換します。

let a = y * z in
let b = x + a in
b

条件式

if x + 1 < y then f x else g y

上の式を、次のように変換します。

let i = 1 in
let a = x + i in
let b = a < y in
if b then
    f x
else
    g y

条件分岐の各分岐は、それぞれ独立してK正規化します。

関数適用

f (g x) (h y)

左から右へ評価するため、次のように変換します。

let a = g x in
let b = h y in
f a b

ブロックの作成

block 0 (f x, y + 1)

上の式を、次のように変換します。

let a = f x in
let i = 1 in
let b = y + i in
block 0 (a, b)

K正規形の性質

  • プリミティブ演算の引数は変数である
  • 関数適用の関数部分と引数は変数である
  • ブロックのフィールドに格納する値は変数である
  • フィールド操作の対象は変数である
  • 条件分岐とタグ分岐の判定対象は変数である
  • 複雑な部分式の結果はletで束縛される
  • 元の式の評価順序がletの順序として明示される

K正規形では、各変数の定義箇所が明確になります。 次のクロージャ変換では、この表現から関数ごとの自由変数を求め、 関数と自由変数をクロージャとして明示します。
