OCaml入門

OCamlとは関数型プログラミング言語です。型推論が得意です。言語仕様が簡潔です。

基本的には、目次の順番で、参照くらいまで学んでいきます。

まず初めに、ocamlのreplを起動してみましょう。replとは、read-eval-print loopの略です。対話的にコードを実行する事ができます。

ocaml
OCaml version 5.3.0
Enter "#help;;" for help.

#

#はプロンプトといって、ここからユーザーに入力を促す記号です。試しに1を入力してみましょう。

# 1;;
- : int = 1

;;が入力の区切りで、そこまでを評価します。

四則演算

整数の四則演算

まずは、整数(int)の四則演算をしてみましょう。

# 1 + 2;;

実行すると結果が帰ってきます。

- : int = 3

引き算、掛け算、割り算もできます。

# 1 - 2;;
- : int = -1
# 2 * 3;;
- : int = 6
# 6 / 2;;
- : int = 3

割り算は整数の商を返します。あまりは返しません。

# 7 / 2;;
- : int = 3

なので、例えば

# 15 / 4 * 4;;
- : int = 12
# 15 * 4 / 4;;
- : int = 15

のようになります。計算順を明示するときは、()で囲います。

# 15 / (4 * 4);;
- : int = 0

あまりを得るには、modを使います。

# 7 mod 2;;
- : int = 1

小数

小数(float)も扱うことができます。ただし、演算子にそれぞれ.を付ける必要があります。

# 3.14 + 2.178;;
Line 1, characters 0-4:
1 | 3.14 + 2.178;;
    ^^^^
Error: The constant "3.14" has type "float"
       but an expression was expected of type "int"

このエラーは、int型の値が期待されたのに、3.14というfloat型の値が与えられたので、不整合を起こしています。

正しく実行するには、

# 3.14 +. 2.178;;
- : float = 5.318

のようにする必要があります。

小数の引き算、掛け算、割り算も同様です。

# 3.14 -. 2.178;;
- : float = 0.96200000000000019
# 3.14 *. 2.178;;
- : float = 6.83892
# 3.14 /. 2.178;;
- : float = 1.4416896235078054

mod.は存在しません。

# 3.14 mod. 2.178;;
Line 1, characters 8-9:
1 | 3.14 mod. 2.178;;
            ^
Error: Syntax error

小数点以下がすべて0なら、その0は省略することができます。

# 1. +. 2.;;
- : float = 3.

型変換

整数と小数が混ざった計算をしたいときは、値に対して明示的に型変換を行ってから計算する必要があります。そのための関数には、例えばfloat_of_intやint_of_floatがあります。

# float_of_int 3;;
- : float = 3.
# int_of_float 3.14;;
- : int = 3

このようにして、後ろに半角スペースあけて数を書くことで、変換を行うことができます。これは後から出てくる関数適用の形と同じです。

これらを用いて次のように計算ができます。

# float_of_int 3 +. 2.;;
- : float = 5.
# 3 + int_of_float 2.;;
- : int = 5

真偽値

真偽値(bool)とは値の一種で、真(true)か偽(false)のどちらかの値をとります。これ以外の値は真偽値には存在しません。

# true;;
- : bool = true
# false;;
- : bool = false

真偽値の演算

真偽値の演算には&&(and)、||(or)、notがあります。

# true && false;;
- : bool = false
# true || false;;
- : bool = true
# not true;;
- : bool = false
# not true && false;;
- : bool = false

これ以外にもいろんな入力を試してみましょう。

比較演算

2つの数を比較する演算子があります。=、<、>、<=、>=、<>などです。ほかのプログラミング言語では、=は==と、<>は!=と書かれることもあります。特にocamlで==は別の意味になってしまうので注意してください。

# 1 = 3;;
- : bool = false
# 1 = 1;;
- : bool = true
# 1 < 3;;
- : bool = true
# 1 > 3;;
- : bool = false
# 3 <= 1;;
- : bool = false
# 1 <> 1;;
- : bool = false
# 1 <> 2;;
- : bool = true

比較演算子には.を付ける必要はありません。

# 3. > 2.;;
- : bool = true

if

if式は、条件に応じて異なる処理を実行するための構文です。条件式、条件式が真の場合の式、条件式が偽の場合の式の3つの式を与えます。

if 条件式 then 式1 else 式2

式1をthen節、式2をelse節とも呼びます。条件式は必ずbool型の値である必要があります。例えば以下のようにできます。

# if true then 1 else 2;;
- : int = 1
# if 1 < 3 then 1 else 2;;
- : int = 1

条件式にはint型の値を与えることができません。

# if 1 then true else false;;
Line 1, characters 3-4:
1 | if 1 then true else false;;
       ^
Error: The constant "1" has type "int" but an expression was expected of type
         "bool"
       because it is in the condition of an if-statement

条件式がfalseに評価されるとき、else節が評価されます。

# if false then 1 else 2;;
- : int = 2
# if 4 <> 9 then 2 else 29;;
- : int = 2

then節とelse節は異なる型ではあってはなりません。

# if 2 <= 3 then true else 2;;
Line 1, characters 25-26:
1 | if 2 <= 3 then true else 2;;
                             ^
Error: The constant "2" has type "int" but an expression was expected of type
         "bool"

論理的に評価されることがありえなくても、型は一致している必要があります。

# if true then 1 else false;;
Line 1, characters 20-25:
1 | if true then 1 else false;;
                        ^^^^^
Error: The constructor "false" has type "bool"
       but an expression was expected of type "int"

このif式はthen節しか実行されることはありえませんが、それでも型が一致している必要があります。

let

変数を宣言するための構文です。値に名前を束縛するというような言い方もします。

let 変数名 = 式

c言語などでは、変数の宣言は領域に対する名前をつけることで行われます。一方、ocamlでは、変数の宣言は値に対する名前をつけることで行われます。なので、例えばc言語ではint a;などと名前だけを宣言することが出来ましたが、ocamlではこのようなことは出来ません。

例えば以下のようにして変数を宣言できます。

# let x = 1;;
val x : int = 1

次にxを参照(名前の中身を確認)してみると値が保存されています。

# x;;
- : int = 1

静的なスコープ

ocamlでは変数の名前が有効である区間が静的に決定されます。

let 変数名 = 式1 in 式2

とすると、式2の中でのみ変数名を参照することができます。

# let y = 1 in y + 2;;
- : int = 3
# y;;
Line 1, characters 0-1:
1 | y;;
    ^
Error: Unbound value "y"

先に定義された変数を新しく再定義することもできます。

# let a = 1 in
  let b = 2 in
  let a = b + a in
  a + 5;;
- : int = 8

let a = b + aが定義される前の時点では、aの値は1だったのですが、新しくaの値をその現在の値である1とbを足したもの、として定義しています。このように、前の変数の名前を新しく上書きすることをshadowingといいます。shadowingは、もう使わない値を意図的に使えないようにすることができるので、ocamlではよく使われます。

ここで重要なのは、c言語などのようにまず記憶領域aがあってそこにはじめに1を入れた。その後にaの値を変更した、というような考え方は出来ないということです。あくまで、名前の中身を上書きしているだけです。難しいかもしれませんが、そのうち理解しなければならないことになるでしょう。

外部ファイルをreplに読み込む

名前をつけることができるようになってきたので、いろいろな名前を先に付けておいてまとめたファイルを作って、毎回let x = ...などと書かなくてもいいようにしましょう。まず、エディタでファイルを適当に作ります。拡張子は.mlです。中身を以下にして保存します。

let pi = 3.14
let e = 2.718

replを起動して、

# #use "ファイル名.ml";;

で読み込みます。

# #use "test.ml";;
val pi : float = 3.14
val e : float = 2.718

これでわざわざreplを起動するたびにlet pi = 3.14などと書く必要がなくなりました。

let a = 1 in
let b = 2 in
let a = b + a in
a + 5

を別のファイルで保存して、読み込むと

# #use "test2.ml";;
- : int = 8

のように、ファイルの中身を直接評価することもできます。また、ここで定義されているaやbは、有効範囲がファイル内のみなので、

# #use "test2.ml";;
- : int = 8
# a;;
Line 1, characters 0-1:
1 | a;;
    ^
Error: Unbound value "a"

のようになります。

コメント

ocamlでは、コメントは(* ... *)の形で書きます。例えば

(* aもbも外部から読み込んだときは参照できない *)
let a = 1 in (* この時点ではa = 1 *)
let b = 2 in (* この時点ではa = 1, b = 2 *)
let (* 新しくaをa = 1, b = 2の状況でb + aとして定義する *)a = b + a in
a + 5

のように自由に書くことができます。

関数

変数を導入したことで、同じ値を何度も書く必要がなくなりました。しかしそれでは値を名付けることはできても、演算については何度も書く必要がありました。関数には名前をつけることができるのですがなんとここには演算も書くことができるので、便利です。関数は

fun 引数 -> 式

というふうに書きます。例えば

# fun x -> x + 1;;
- : int -> int =

は受け取った引数に1を足す関数です。この引数に1を渡すには

# (fun x -> x + 1) 1;;
- : int = 2

のように後ろに空白を挟んで引数を書きます。引数が複数ある場合は

fun 引数1 引数2 ... -> 式

のように書きます。例えば

# fun x y -> x + y;;
- : int -> int -> int =

のように書くことができます。これに引数を渡すには

# (fun x y -> x + y) 1 2;;
- : int = 3

のようにして、引数と同じように空白で区切って並べて書きます。

高階関数

引数が複数ある関数を1つの引数を受け取る関数で表現することをカリー化といいます。例えば

fun x y -> x + y

は

fun x -> (fun y -> x + y)

のように表現できます。これは引数としてxを受け取って、「引数としてyを受け取ってx + yを返す関数」を返す関数です。このように関数が関数を返すような関数を高階関数と呼びます。

部分適用

関数の引数の全てではなく一部だけの引数を渡す事もできます。

# (fun x y -> x + y) 2;;
- : int -> int =

とすると、先程のカリー化の解釈によればxとして2を受け取って、「引数としてyを受け取って2 + yを返す関数」を返します。なのでここで返される関数はfun y -> 2 + yです。このように引数を一部だけ渡して新しい関数を得ることを部分適用といいます。

関数に名前をつけること

関数にも名前をつけることができます。これまでの方式と同じく

let 関数名 = fun 引数 -> 式

のように書くことができます。例えば

# let add1 = fun x -> x + 1;;
val add1 : int -> int =

のように名前をつけることができます。これに値を適用するには

# add1 2;;
- : int = 3

のように、関数名の後ろに空白を挟んで引数を書きます。

省略構文

関数に名前をつけることは非常によくあることなので省略構文が用意されています。

let 関数名 引数1 引数2 ... = 式

のように書くことができます。例えば

# let add x y = x + y;;
val add : int -> int -> int = 
# add 1 2;;
- : int = 3

のように書くことができます。

部分適用は名前をつけることで新しい特化した関数を作るということに使えます。例えば

let log base x = ...

というような関数が存在したときに、

let ln = log e

のように書くことができ、自然対数を底とした対数関数を簡単に作ることができます。

関数のスコープ

let a = 3 * 2 in
  let f b = a + b in
    let a = 5 in
      f 1

の計算結果は7です。難しいのはfのaがどのaを指すかということです。ocamlは関数の本体式の中で使用される変数は、その関数が定義された段階での変数を参照します。ですからここではaは3 * 2の値、つまり6を指します。実際に実行してみても

# let a = 3 * 2 in
    let f b = a + b in
      let a = 5 in
        f 1;;
Line 3, characters 8-9:
3 |     let a = 5 in
            ^
Warning 26 [unused-var]: unused variable a.

- : int = 7

のように、a = 5が使われていないという警告が表示されます。

再帰的な関数

相互再帰的な関数

組

複数の値をまとめたもので、順序に依存します。

パターンマッチというのが出来ます。

レコード

組のそれぞれの要素に、位置の代わりの識別子として名前をつけたものです。

パターマッチが出来ます。

ヴァリアント

レコードの双対で、どれか1つの値を保持する型です。他の言語では、「代数的データ型」などとも呼ばれます。

パターンマッチが出来ます。

リスト

再帰的なデータ構造です。空リストはリストです。リストの先頭に要素を追加したものもリストです。

パターンマッチが出来ます。
